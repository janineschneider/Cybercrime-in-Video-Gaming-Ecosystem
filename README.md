# Achievement Unlocked: Let’s Get Hacked!  
## An Empirical Study of Cybercrime in the Video Gaming Ecosystem

---

## Overview

This repository contains additional information, datasets, and visualizations accompanying the paper *"Achievement Unlocked: Let’s Get Hacked! - An Empirical Study of Cybercrime in the Video Gaming Ecosystem"*.

The materials include:
- Survey design details
- User report collection details
- Survey and user report analysis details
- Labeled datasets used for analysis
- Figures and plots supporting the empirical findings
- Interview and survey data from the user study

---

## Repository Structure

### `Additional_Data.pdf`
  Contains supplementary methodological details, including:
  - Survey questions and distribution strategy
  - Keyword selection and data collection process
  - Subforum selection for data scraping
  - Filtering prompts for user reports
  - Labeling schema for user study and scraped data
  - Category definitions and coding guidelines
  - Full category/code descriptions for qualitative analysis

### `Plots/User_Report/`
Visualizations based on scraped user-generated content:

- Attack vectors over time  
- Device usage trends  
- Game mode distributions  
- Game distributions
- Incident type distributions  
- Platform distributions  
- Monthly posting activity (GOG, Reddit, Steam)  
- Keyword distributions and trends  
- Text length distribution  
- Topic evolution over time  
- Topic distribution by device  

### `Plots/User_Study/`
Survey-based visualizations:

- Cybercrime experience distribution  
- Country of residence distribution  
- Education levels  
- Gender distribution  
- Age distribution  
- Effects of cybercrime incidents  
- Gaming behavior and engagement patterns  
- Preferred gaming, modification and distribution platforms   
- Operating systems used  
- Security measures adoption  
- Weekly playtime distribution  
- Singleplayer vs. multiplayer preferences  

### `Data/User_Report/`
- Labeled posts  
- Co-occurrence matrix  
- Correlation matrix  

### `Data/User_Study/`
- Survey responses  
- Interview transcripts:
  - Interview 1  
  - Interview 2
